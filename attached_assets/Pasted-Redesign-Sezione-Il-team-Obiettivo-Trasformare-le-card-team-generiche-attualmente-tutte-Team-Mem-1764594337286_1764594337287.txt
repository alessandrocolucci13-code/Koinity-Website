Redesign Sezione "Il team"
Obiettivo
Trasformare le card team generiche (attualmente tutte "Team Member" + "Role") in profili coinvolgenti, personalizzati e interattivi.
Problema Attuale

Avatar generici gialli identici
Nessuna personalizzazione ("Team Member" ripetuto 3 volte)
Nessun hover effect interessante
Mancanza di informazioni sui membri
Layout statico e poco professionale

JavaScript per Animazioni Scroll
javascript// Intersection Observer per animazioni entrata
const observerOptions = {
  threshold: 0.2,
  rootMargin: '0px 0px -50px 0px'
};

const teamObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
    }
  });
}, observerOptions);

document.querySelectorAll('.team-card').forEach(card => {
  teamObserver.observe(card);
});
