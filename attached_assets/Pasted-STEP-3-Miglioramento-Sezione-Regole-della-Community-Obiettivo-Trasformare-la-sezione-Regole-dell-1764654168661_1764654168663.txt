STEP 3: Miglioramento Sezione "Regole della Community"
Obiettivo
Trasformare la sezione "Regole della Community" da un semplice box blu con lista numerata a una sezione moderna, accattivante e facilmente leggibile che ispiri rispetto e coinvolgimento.
Problema Attuale

Box blu generico con bordo troppo spesso
Lista numerata troppo compatta e poco leggibile
Mancanza di gerarchia visiva tra le regole
Nessun elemento visivo che renda la sezione coinvolgente
Testo troppo denso e poco invitante

JavaScript per Scroll Animation
javascript// Intersection Observer per animazioni scroll
const rulesObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.style.animationPlayState = 'running';
    }
  });
}, {
  threshold: 0.1,
  rootMargin: '0px 0px -50px 0px'
});

document.querySelectorAll('.rule-item').forEach(rule => {
  rule.style.animationPlayState = 'paused';
  rulesObserver.observe(rule);
});
