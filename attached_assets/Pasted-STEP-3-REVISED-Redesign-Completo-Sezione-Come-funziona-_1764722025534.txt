STEP 3 (REVISED): Redesign Completo Sezione "Come funziona"
Problema con l'Implementazione Attuale
La versione attuale ha diversi problemi:

Layout mobile-first poco adatto a desktop (sembra una versione mobile allungata)
Linea centrale troppo prominente e invasiva
Card troppo separate mancanza di coesione visiva
Numeri badge dispersi lungo la linea invece di essere parte delle card
Troppo spazio vuoto e poco contenuto visibile
Mancanza di gerarchia tra gli elementi
Non comunica un "flow" chiaro e professionale


Nuovo Approccio: Grid Compatta con Card Integrate
Obiettivo
Creare una sezione più compatta, professionale e desktop-friendly che mostri tutto il processo in modo chiaro e scannable.

Design Proposto: Grid 2x2 con Connettori Sottili
Desktop Layout:

│   [icon/visual] │    │   [icon/visual] │

│   3. Organizza  │ ←  │   4. Sala piena │
│   [icon/visual] │    │   [icon/visual] │

javascript// Intersection Observer per animazioni
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.style.animationPlayState = 'running';
    }
  });
}, { threshold: 0.2 });

document.querySelectorAll('.step-card').forEach(card => {
  card.style.animationPlayState = 'paused';
  observer.observe(card);
});
