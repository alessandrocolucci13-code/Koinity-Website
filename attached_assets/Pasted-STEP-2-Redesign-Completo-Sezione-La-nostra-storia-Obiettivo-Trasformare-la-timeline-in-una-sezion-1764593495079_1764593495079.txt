STEP 2: Redesign Completo Sezione "La nostra storia"
Obiettivo
Trasformare la timeline in una sezione più moderna, pulita e visivamente accattivante, eliminando l'aspetto "troppo tecnico" della timeline attuale.
Modifiche da implementare:
1. Nuovo Layout - Card Storytelling
Invece della timeline verticale con linea gialla, creare card narrative sovrapposte con effetto "storia che si sviluppa":
Struttura proposta:
┌─────────────────────────────────────┐
│  🎬  2024 - L'inizio                │
│  [Breve testo emozionale]           │
└─────────────────────────────────────┘
      ┌─────────────────────────────────────┐
      │  💡  Sviluppo - La piattaforma      │
      │  [Breve testo emozionale]           │
      └─────────────────────────────────────┘
            ┌─────────────────────────────────────┐
            │  🚀  Oggi - La crescita             │
            │  [Breve testo emozionale]           │
            └─────────────────────────────────────┘
2. Styling delle Card Storia
Card Design:
css/* Ogni card con stile unico */
.story-card {

    rgba(255,255,255,0.08) 0%,

  border-radius: 20px;

  position: relative;
  overflow: hidden;
}

/* Effetto "glass morphism" */
.story-card::before {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: linear-gradient(45deg, 
    transparent 30%, 
    rgba(255,214,0,0.1) 50%, 
    transparent 70%);
  opacity: 0;
  transition: opacity 0.5s;
}

.story-card:hover::before {
  opacity: 1;
}
3. Layout Alternato (Zigzag)

2024: Allineato a sinistra, larghezza 60%, margin-right: auto
Sviluppo: Allineato a destra, larghezza 60%, margin-left: auto
Oggi: Allineato a sinistra, larghezza 60%, margin-right: auto

Mobile: tutte le card full-width centrate

5. Animazioni Progressive
css/* Entrata card con fade + slide */
@keyframes slideInLeft {
  from {
    opacity: 0;
    transform: translateX(-50px);
  }
  to {
    opacity: 1;

  }
}

@keyframes slideInRight {
  from {
    opacity: 0;
    transform: translateX(50px);
  }
  to {
    opacity: 1;
    transform: translateX(0);
  }
}

/* Applicare con Intersection Observer */
.story-card.animate-left {
  animation: slideInLeft 0.8s cubic-bezier(0.4, 0, 0.2, 1) forwards;

.story-card.animate-right {

}
