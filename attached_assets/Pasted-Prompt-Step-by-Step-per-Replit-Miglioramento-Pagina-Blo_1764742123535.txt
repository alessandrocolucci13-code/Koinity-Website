Prompt Step-by-Step per Replit - Miglioramento Pagina "Blog & Aggiornamenti"
STEP 1: Miglioramento Hero Section "Blog & Aggiornamenti"
Obiettivo
Rendere la hero section più moderna, coinvolgente e distintiva, trasformandola da semplice intestazione a una sezione che comunichi il valore del blog e inviti all'esplorazione.
Problema Attuale

Titolo e sottotitolo molto semplici e statici
Nessun elemento visivo distintivo
Mancanza di call-to-action o elementi interattivi
Nessuna categorizzazione o filtro visibile
Layout piatto senza profondità
Nessuna indicazione sulla frequenza di aggiornamento

const filterTabs = document.querySelectorAll('.filter-tab');
filterTabs.forEach(tab => {
  tab.addEventListener('click', (e) => {
    e.preventDefault();
    
    // Remove active class from all
    filterTabs.forEach(t => t.classList.remove('active'));
    
    // Add active to clicked
    tab.classList.add('active');
    
    // Filter logic here (based on data attributes or href)
    const category = tab.textContent.trim();

  });
});
