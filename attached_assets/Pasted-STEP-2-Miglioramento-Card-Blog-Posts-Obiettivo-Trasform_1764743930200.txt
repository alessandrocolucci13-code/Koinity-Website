STEP 2: Miglioramento Card Blog Posts
Obiettivo
Trasformare le card blog attuali da semplici box blu con bordo a card moderne, visivamente accattivanti e facilmente scannable che invitino al click.
Problema Attuale

Card troppo semplici con bordo blu spesso
Immagini poco integrate nel design
Mancanza di gerarchia visiva tra titolo, descrizione e metadata
Nessun hover effect interessante
Layout rigido poco flessibile
Mancanza di indicatori visivi (categoria, tempo di lettura, ecc.)

JavaScript per Scroll Animation
javascript// Intersection Observer per animazioni card
const cardsObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.style.animationPlayState = 'running';
    }
  });
}, {
  threshold: 0.1,
  rootMargin: '0px 0px -50px 0px'
});

document.querySelectorAll('.blog-card').forEach(card => {
  card.style.animationPlayState = 'paused';
  cardsObserver.observe(card);
});
